long funbincoe(int a, int b) {
    long r1, r2, r3;
    r1 = r2 = r3 = 1;
    for (int i = 1; i <= a; i++)      r1 *= i;
    for (int i = 1; i <= b; i++)      r2 *= i;
    for (int i = 1; i <= (a - b); i++) r3 *= i;
    return r1 / (r2 * r3);
}

long BinomialCoefficient(int n, int k) {
    long nFactorial = Factorial(n);
    long kFactorial = Factorial(k);
    long nMinusKFactorial = Factorial(n - k);
    return nFactorial / (kFactorial * nMinusKFactorial);
}

    do {
        stop = true;

            if (numbers[i] > numbers[i+1]) {

    }

}

double std(double[] array) {

    foreach (double i in array) sum+=i; //calculating the sum
    double avg=sum/array.Length; //sample size
    double ssd=0; //sum of squared differences

    return s; //result

    double sum = 0;
    foreach (double number in sample)
        sum += number;
    double mean = sum / sample.Length;

    double squaredDifferencesSum = 0;
    foreach (double number in sample)
        squaredDifferencesSum += (number-mean) * (number-mean);

}

Odgovor

SRP u Singletonu

Trik-pitanje: Singleton SRP krši, i to je poanta. Klasa uz svoj stvarni posao preuzima i drugu odgovornost — upravljanje vlastitim životnim ciklusom (privatni konstruktor, statičko polje, kontrola broja instanci). SRP u Lancu odgovornosti

Svaki obrađivač zna jedno: je li ovaj zahtjev njegov i što s njim učiniti. Ne zna tko je iza njega, ni koliko ih ima, ni što se događa ako ga nitko ne obradi. Odgovornost prosljeđivanja i redoslijeda izdvojena je u baznu kariku i u klijenta koji lanac slaže. Zato svaki razred ima točno jedan razlog za izmjenu — promjenu vlastitog pravila.

OCP u Strategiji

Novo ponašanje se dodaje novom klasom koja ostvaruje sučelje strategije. Kontekst se pritom ne dira — on i dalje zove istu metodu istog sučelja. Otvoreno za proširenje (nova strategija), zatvoreno za izmjenu (kontekst i postojeće strategije ostaju netaknute). Isti zadatak bez obrasca bio bi switch koji raste sa svakim novim algoritmom.

DIP u Strategiji

Kontekst je modul visoke razine, konkretni algoritmi su niska razina. Kontekst ne ovisi ni o jednom od njih — drži polje tipa IStrategy, a ne QuickSort. Oboje ovise o apstrakciji, i to je doslovno „inverzija“: bez obrasca bi strelica ovisnosti išla od konteksta prema konkretnom algoritmu, a ovako obje idu prema sučelju.

10 Koji je obrazac prikladan za dani zadatak? — svih osam opisa 3 boda · 8 pojavljivanja

U opisu je uvijek jedna rečenica koja odaje obrazac. Pronađi nju i ostalo je opis domene. Ispod je svih osam zadataka; pokušaj svaki prije otvaranja.

  1. Generator pseudo-slučajnih brojeva s metodama za interval [a,b], dostupan unutar cijelog sustava.
  2. Nadzor proizvodnje i potrošnje energije; više raznorodnih komponenti automatski obaviješteno o promjeni, odnos se ostvaruje i prekida dinamički, nove komponente bez utjecaja na klijentski kôd.
  3. Nadzor protoka plina; nadzorni elementi obavještavaju sve koje promjena zanima, dinamičko započinjanje i odustajanje, pratitelji u raznim izvedbama (mail, bilježenje, prikaz).
  4. MooTube: korisnici prate pojedinog kreatora i pri objavi dobivaju obavijest; velik broj pratitelja; praćenje dinamičko.
  5. Didaktički alat za djecu: zaslon čuva kolekciju oblika koji nisu javno dostupni; treba undo i povratak na ranije stanje; čuva se zadnjih deset stanja; obavezno očuvati enkapsulaciju.
  6. Alat za predškolsku djecu: konkretni oblici (kružnica, pravokutnik) i složeni oblici koji se sastoje od više osnovnih ili drugih složenih; klijent svima jednako traži iscrtavanje i krajnje točke.
  7. Rezervacija smještaja: klijent koristi IBookingProvider.GetAccomodation(int, int); treba uključiti vanjsku AirBookService.RetrieveAll(Location) koja ne ugrađuje niti može ugraditi to sučelje; klijentski kôd ne treba biti svjestan promjene.
  8. Slanje poruka uz kriptografske hash funkcije; treba podržati različite inačice i naknadno dodavati nove; moraju biti izmjenjive tijekom izvođenja bez ponovnog prevođenja.
